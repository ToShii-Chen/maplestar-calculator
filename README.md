# 楓星計算工具

使用 React + TypeScript + Vite 建立的楓星表攻計算網站。可部署於 GitHub Pages。

## 功能

- 頂部可切換的「怪物圖鑑」「無視防禦計算」「欄位」及「+」新增角色欄位
- 怪物圖鑑全域共用；每個角色欄位的傷害計算、裝備及名稱獨立
- 七組無視防禦乘算、八組 BOSS 防禦增傷比較
- 依照《楓星傷害試算-精靈.xlsx》建構基本設定、技能、套裝、藥水、裝備與表攻上限公式
- 欄位重新命名（最多 15 字）
- localStorage 自動儲存，以及 JSON 備份匯入、匯出

## 執行

```bash
npm install
npm run dev
```

## 打包

```bash
npm run build
```

產物在 `dist/`。`vite.config.ts` 的 `base: './'` 可用於 GitHub Pages 子路徑。

## 公式說明

- 無視防禦合併：`100 × [1 − Π(1 − 各來源無視% / 100)]`
- BOSS 傷害占比：`max(0, 100 × [1 − BOSS防禦% / 100 × (1 − 無視% / 100)])`
- 增傷：`(新傷害 / 原傷害 − 1) × 100%`。若原傷害為 0 且新傷害大於 0，顯示「無法計算」。
- 表攻上限：`floor(固定攻擊力 × (1 + 攻擊力%) × [固定主屬性 × (1 + 主屬性%) × 4 + 固定副屬性 × (1 + 副屬性%)] × 武器係數 × 0.01)`
- 楓葉祝福：`floor((等級 + 1) / 2)%`，僅加成能力配點的基礎主副屬性。
- 怪物圖鑑的「全屬性」套用至角色選定的主、副屬性；「全屬性(%)」套用至兩者的百分比。
- 原 Excel 的表攻上限公式未使用武器熟練度、總傷害%、BOSS傷害%、無視防禦%，故本版不擅自納入。這些全域資料保留以供後續功能擴充。
- 原 Excel `傷害計算!B26` 的技能副屬性加總範圍是 `E4:Q4`，不含最後一格 `R4`；網頁版依照 Excel 保留此範圍。

## 待確認與限制

- 「總傷害(%)」「BOSS傷害(%)」「無視防禦(%)」目前只記錄，不影響 Excel 表攻上限。
- Excel 的技能副屬性末格 `R4` 不參與計算是否為筆誤，需確認；目前程式依照 Excel **不包含**最後一格。
- Excel 裝備防具與飾品沒有提供潛能攻擊力的儲存/計算公式；介面顯示欄位但計算只計入武器類潛能攻擊力。
- 所有數值僅儲存在目前瀏覽器，請定期匯出 JSON 備份。清除瀏覽器資料會遺失本機內容。
